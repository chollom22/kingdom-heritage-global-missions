Dataset information

Source: Midvash open Bible data repository. The repository identifies its KJV text as public domain and provides one JSON file per book. The importer stores the KJV version code as KJV and uses the full English book names.

An internet connection is needed during this one-time import. After the verses are stored, your channel page can retrieve the verse text from Supabase rather than from an external Bible API.
